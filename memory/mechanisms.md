## 一、决策流程（五层校验）

### 1.1 独立提方案
不同 AI **独立**给出判断（不互相看答案）。

### 1.2 交叉验证
两家 AI 给相反答案时：
- ❌ 不取中位数（可能两边都错）
- ✅ 找分歧点，定点验证

**实例**：Kimi 说"闲鱼放弃"，DeepSeek 说"继续"。
→ 定点验证：真因是"选词错"，不是"平台死"。

### 1.3 魔鬼代言人（强制）
团队一致同意 ≠ 正确。必须有人唱反调。

**实例**：开源引流，3家同意 → 唱反调后推翻（模式错配）。

### 1.4 证据核实
**AI 声称 ≠ 事实**。

| 级别 | 判据 | 可信度 |
|------|------|--------|
| L0 | 可执行验证 | ✅ 可信 |
| L1 | 产出物（文件非空）| ✅ 可信 |
| L2 | 推理链（无物证）| ⚠️ 待确认 |
| L3 | 纯文字声称 | ❌ 不可信 |

### 1.5 实施 + 回滚
不可逆操作必须有回滚方案。

**远程改配置标准流程**：
```
① 备份 ② 验语法 ③ 设自动回滚保险
④ 平滑重载 ⑤ 验证 ⑥ 取消保险
```

## 心跳守护（Heartbeat Guardian）

> 新增：2026-09-30（排查邮箱告警后）

### 问题
沙箱没有 systemd，心跳只能跑在会话进程里。
会话/环境重启 → hb_loop 死 → hc-ping 超时 → **用户邮箱收告警**。

### 数据
369 次心跳记录中，断档 1 次（09-29 09:19→13:48，269 分钟）。

### 解法
`hb_guardian.py` 常驻守护：
- 每 60 秒检查一次
- 判据：心跳新鲜度（>300秒=死亡）**或** hb_loop 进程不在
- 触发 → `setsid` 重新拉起 hb_loop.py

### 关键坑（已修）
`pgrep -f hb_loop.py` 会匹配 sudo/shell 包装层（假阳性 5 个）。
→ 改成解析 `ps -eo pid,cmd`，只认真正的 `python3 .../hb_loop.py`。

### 启动
```bash
python3 hb_guardian.py loop    # 常驻（用 process 工具起）
```

### 验证
2026-09-30 21:25 杀掉 hb_loop → 守护 60 秒内自动拉起 ✅

## Healthchecks 邮件判读规则（2026-09-30）

```
【怎么分辨"真故障"和"恢复通知"】
· 标题含 "is DOWN" / "DOWN" → 🔴 真故障，立刻查
· 标题含 "is UP" / "UP" + "downtime lasted" → ✅ 恢复通知，正常
· "Last Ping Type: Success" → ✅ 当前正常
· "Total Pings" 持续增长 → ✅ 探针在跑

【什么时候会收到"恢复通知"（正常）】
· 手动重启服务时（探针短暂中断）
· 部署/修改代码时
· 服务器维护时

【判读口诀】
"UP + Success = 好消息，不用管"
"DOWN = 立刻查"
```

## ⚠️ 已知误报：proxy-token.txt=640（2026-09-30 再修）

```
【现象】health_probe 报 "/opt/masterd/data/proxy-token.txt=640"
【真相】这是【误报】—— 640 是 ACL 导致的正常显示
  · setfacl 后，ls 显示 640+（多一个+）
  · 640+ACL = "属主全权 + 指定用户只读"（比600更精确）

【历史】
· 之前改过探针（允许640）→ decisions.md
· 但 health_probe.py 没改到 → 又报了
· 2026-09-30 已修（第177行：允许 600/400/640）

【教训】
"同一问题的多个检查脚本要同步改"
→ 否则修了一个，另一个还在报
```

## 铁律：脚本路径必须自适应（2026-09-30）

```
【踩坑】
· 脚本在"沙箱"和"服务器"两处跑
· 但文件路径不同：
  沙箱：/app/agent/state/
  服务器：/opt/masterd/memory/
· 硬编码路径 → 换环境就挂

【铁律】
所有"双环境"脚本，开头必须路径自适应：
```python
if Path('/app/agent/state/PRINCIPLES-LOCKED.txt').exists():
    STATE = Path('/app/agent/state')      # 沙箱
elif Path('/opt/masterd/memory/PRINCIPLES-LOCKED.txt').exists():
    STATE = Path('/opt/masterd/memory')   # 服务器
```

【判例】
· behavior_audit.py：查沙箱路径 → 服务器上找不到 → 失败
· 2026-09-30 已修
```
