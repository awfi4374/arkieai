## 七、⭐ 掘金/社媒的"节奏纪律"（2026-10-01 董事长定）

```
【董事长原话】
"你这边要是真人啊，不要发的太勤了，这个度你要把控。毕竟这个是新号。
 还有你这边不要主攻掘金这边，掘金这边的人群都是技术。
 掘金这边是让我们练技术的。"

【纪律】

① 节奏（像真人，不像机器人）
❌ 禁止：一天发多条、间隔<2小时
❌ 禁止：连续几天高频
✅ 应该：每天最多1条，间隔>4小时
✅ 应该：有"停顿"（不是天天发）
✅ 应该：回应评论 > 发新内容（互动优先）

② 定位（掘金=练技术，不是获客主战场）
· 掘金人群 = 技术人 → 不是我们的目标客户（中小老板）
· 掘金的用途 = 练技术 + 练内容 + 建立"真实人设"
· 不是：获客主渠道

③ 获客主战场要找"非技术人群"：
· 中小企业老板在哪？（抖音/快手/小红书/本地社群/行业群）
· 这些才是"愿意付钱"的人

【判据】
新号 + 高频 = 被判定为"营销号/机器人" → 限流 + 招黑
新号 + 低频 + 真实互动 = 像"真人" → 慢慢积累
```

## 八、⭐ 渠道战略修正（2026-10-01）

```
【原来（错的）】
主攻掘金 → 引到工具站 → 首单

【现在（修正）】
· 掘金 = 练手（练内容/练互动/建人设）
· 获客主战场 = 找"非技术人群"的渠道
  （中小企业老板聚集地）

【为什么】
掘金的人是"技术人"——他们自己会做AI工具，
不是"愿意为AI工具付钱的客户"。
```
